# Project File Hub 1.0.0

Project File Hub 1.0.0 是首个正式版本，面向 Windows 11 x64，专注于本机项目范围内的文件浏览、整理与预览。

## 主要功能

- 登记多个本机项目，一次只激活一个工作空间，所有导航与文件操作受项目根目录边界保护。
- 使用惰性目录树、网格/列表、自然排序、文件名搜索、类型筛选和显式“含子文件夹”范围浏览文件。
- 按 `Space` 预览图片、Markdown、文本、代码、Word 正文、音视频、文件夹摘要及 Windows 可提供的其他缩略图。
- 支持重命名、复制、粘贴、移动、拖放、多选、移入回收站、资源管理器定位，以及拖到其他 Windows 应用。
- 恢复各项目的工作区状态，提供三套 Focus Canvas 主题，并可选择在通知区域继续索引。
- 提供免管理员权限的当前用户安装器，以及自包含便携 ZIP。

## 图片稳定性改进

- 缩略图与大图预览各自使用有字节和条数预算的 LRU 缓存，并限制并发与等待队列；相同图片请求会合并。
- 切换文件夹、搜索、项目、预览，回收文件容器，隐藏到通知区域或关闭窗口时，会使旧请求失效并释放界面引用。
- SQLite 子目录查询、文件名搜索和排序在界面线程之外执行，并与普通目录浏览共用查询与排序规则。
- 本地诊断日志记录图片队列/缓存状态、文件视图失败和异常退出证据。

核心回归测试通过 36/36。原生候选另完成了 8 次目录切换和 8 次大图切换，没有观察到新的崩溃。这些改动降低了已知任务堆积和旧结果回填风险；有限检查不证明历史原生 WinUI 崩溃只有一个根因，也不等同于完整的长期压力验证。

## 系统要求与已知限制

- 支持 Windows 11 x64。
- 安装器没有 Authenticode 代码签名。Windows 可能显示“未知发布者”或 SmartScreen 提示；运行前请核对同目录的 SHA-256 文件。
- 应用内图片预览保留最长边不超过 4096 像素的显示数据。复制图片或使用默认应用打开时使用未修改的原文件。
- 图片格式依赖 Windows 解码器；系统无法解码的格式会显示不可用提示。
- Word 预览提取受限长度的已保存 `.doc` / `.docx` 正文，不还原原始分页、图片、页眉页脚或完整排版。
- 可选 MCP 适配器为独立只读进程，默认关闭。
- 长期高频切换、关闭预览后导航及通知区域隐藏/恢复的完整压力验证尚未完成。
